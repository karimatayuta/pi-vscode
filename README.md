# Pi Agent for Visual Studio Code

VS Codeの右側でPiと会話しながら、コードの調査・計画・編集・動作確認を進めるための
コーディングエージェントです。確認してほしいファイルを入力欄へ添付し、普段の言葉で依頼できます。

**最短の流れ:** VSIXをインストール → AIプロバイダーを接続 → モデルを選択 → 質問を送信

> **プレビュー版です。** Piがファイル変更やコマンド実行の許可を求めたときは、対象と内容を
> 確認してから許可してください。

## 3ステップで開始

### 1. インストールする

この拡張機能は、現在VSIXファイルで配布します。

1. VS Code左側の **Extensions（拡張機能）** を開きます。
2. ビュー右上の `…` から **Install from VSIX…** を選びます。
3. 配布された `pi-agent-*.vsix` を選びます。
4. VS Codeで、Piに相談したいプロジェクトの**フォルダー**を開きます。
5. コマンドパレット（macOS: `⇧⌘P`、Windows/Linux: `Ctrl+Shift+P`）で
   `Pi Agent: Open Chat` を実行します。

Pi Agentは右側のサイドバーに開きます。VS Codeからフォルダーを信頼するか確認された場合は、
内容を把握しているプロジェクトだけを信頼してください。

### 2. AIプロバイダーとモデルを設定する

1. チャット入力欄の下にある **Choose model**（または現在のモデル名）を押します。
2. **Configure provider…** を選びます。
3. プロバイダーID（例: `anthropic`、`openai`）と、そのプロバイダーのAPIキーを入力します。
4. 一覧からモデルとReasoning effortを選び、**Apply** を押します。

モデルとReasoning effortは未適用の変更としてまとめて表示され、**Apply** するまで現在のチャットには
反映されません。同じ設定を新しいチャットでも使う場合は **Set default** を押してください。
Set defaultは、選択中の設定を現在のチャットにも同時に適用します。
APIキーはVS Codeが提供する安全な資格情報保管領域へ保存され、チャット画面や
プロジェクト設定には保存されません。

コマンドパレットの `Pi Agent: Configure Provider…` から接続することもできます。

### 3. 最初の質問を送る

まずは入力欄左下の操作モードを **Plan** にして、次のような読み取りだけの質問を試すと安全です。

```text
このプロジェクトの構成と、最初に読むべきファイルを簡潔に説明してください。変更はしないでください。
```

変更も依頼するときは **Ask** に切り替えます。Askでは、Piが編集やコマンド実行の前に確認します。
入力欄で `Enter` を押すか、右側の送信ボタンで依頼を送信できます。改行は `Shift+Enter` です。

## ファイルを一緒に見てもらう

Explorerのファイルまたはフォルダーを、**Ask Pi…と表示された入力フォームの内側へそのまま
ドラッグ＆ドロップ**します。入力欄に添付チップが現れたことを確認してから送信してください。

ほかにも次の追加方法があります。

- 入力欄の添付ボタンからファイルまたはフォルダーを選ぶ
- 入力欄で `@` を入力し、ワークスペース内のファイルを検索する
- Explorerで右クリックし、**Add to Pi Agent Context** を選ぶ
- エディターの選択範囲を右クリックし、**Add Current Selection to Context** を選ぶ

添付チップは、`×` で外すまで次の依頼にも使用されます。不要になったファイルは外してください。

### ドラッグ＆ドロップの制約

- 現在開いているローカルワークスペース内のファイルとフォルダーだけを添付できます。
- ワークスペース外の項目とシンボリックリンクは拒否されます。バイナリファイルは、チップが
  表示されても内容を送信するときにスキップされます。
- 大きすぎるファイルやフォルダーは、安全のため省略またはスキップされることがあります。
- エディターで選択した文字をドラッグしても、ファイル添付としては扱いません。
- OSやVS Codeの組み合わせによっては、チャット画面へファイルの場所が届かず、チップが
  現れない場合があります。その場合は、添付ボタン、`@`検索、Explorerの右クリックを使用します。

## 操作モードを選ぶ

操作モードはチャットごとに選択できます。迷った場合は、既定の **Ask** を使用してください。

| モード | Piに許可すること | 向いている場面 |
| --- | --- | --- |
| **Plan** | 読み取りと検索のみ。編集とコマンドはブロック | 調査、説明、作業計画 |
| **Ask** | 読み取りは自動。編集やコマンドの前に確認 | 通常の開発作業 |
| **Auto Edit** | ワークスペース内の編集と通常のコマンドは自動。削除や高リスク操作は確認 | 編集方針が固まった作業 |
| **Full Access** | ファイル操作とコマンドを原則自動許可。コマンドはワークスペース外やネットワークにも到達可能 | 内容と影響を判断できる利用者向け |

Full Accessは確認画面を経て現在のセッションにだけ適用され、次回用の既定値としては保存されません。
信頼していないワークスペースではPlan以外を選択できません。

Auto Editでは、通常と判定されたコマンドは個別確認なしで実行されます。削除コマンドや既知の
高リスクパターンは実行前に確認します。ただし、スクリプトなどを介した間接的な影響は完全には
判定できません。

Full Accessでは、既知の削除・高リスクパターンを含むコマンドが個別確認なしで実行されます。
built-in toolで直接検出できた機密ファイルやワークスペース外へのアクセスだけは引き続き確認します。
ただし、コマンド内部からの機密ファイル、ネットワーク、ワークスペース外への間接アクセスを拡張機能が
完全に判定することはできません。影響を判断できない依頼ではAskを使用してください。

確認画面では、対象ファイルや実行コマンドを読んでから判断してください。通常の操作では
**Allow once**、**Allow for session**、**Deny** を選べます。確認対象となった危険な操作は
**Run once** または **Deny** だけになり、セッション単位では許可できません。セッション中の許可は
`Pi Agent: Reset Saved Permissions` で取り消せます。

## 入力欄で使える便利な操作

| 操作 | できること |
| --- | --- |
| `/` | このセッションで利用可能なPiコマンド、プロンプト、Agent Skillを検索 |
| `@` | 添付するワークスペース内ファイルを検索 |
| モデル名 | プロバイダー、モデル、Reasoning effortを変更 |
| Usage | 使用中・残りコンテキスト、正確なsession token合計、推定costを確認 |
| Stop | 進行中の応答とツールを停止 |

`/` の候補は現在のPiセッションから取得します。Agent Skillも候補から選べるため、コマンド名を
覚える必要はありません。Piの作業中は内容を日本語で要約し、完了後は使用したツールを
`Tools N件` にまとめます。開くと `read`、`ls`、`find` などの詳細を確認できます。

Usageでは、現在のコンテキスト使用量と残量、session全体のInput / Output / Cache tokenを確認できます。
応答中は数値がLive更新され、競合を避けるため **Compact this chat** は応答完了またはStopまで無効になります。

Usageのcostは、モデルカタログの単価とtoken使用量から求める**参考推定値**です。
サブスクリプション利用中でもカタログ価格があればReference token costとして表示されますが、
プランでの充当状況やプロバイダーの請求額を表すものではありません。価格情報がない場合だけ
Unavailableになります。

## チャットと表示を整える

- 複数のチャットをタブで開き、待機・動作中・エラーの状態を色で確認できます。
- ユーザーが送信した依頼は、送信直後に`Your request`付きのグラデーションカードとして右側に表示されます。
- 完了後の思考内容は、`Thought`を開くと確認できます。
- タイトルは最初の質問から自動作成され、タブのメニューから変更・再生成できます。
- Markdownの見出し、表、タスクリスト、コードブロック、リンク、Mermaid図を表示できます。
- 完了したPiの応答はコピーアイコンからMarkdown全文をクリップボードへコピーできます。
- URLはブラウザーへ、ワークスペース内のファイル参照は該当するファイル・行へ移動できます。
- 上部の `…` → **Settings and View Design** から、テーマ、フォント、文字サイズ、間隔、
  Piのチャット内アイコンを変更できます。

Mermaidは外部CDNを使わず、応答完了後にローカルで描画します。対応していない記法や構文エラーが
ある場合は、図の代わりに元のMermaidソースを表示します。

## 安全に使うために

- **送信内容を確認する:** 質問と添付ファイルの内容は、選択したAIモデルのプロバイダーへ
  送信されます。秘密鍵、パスワード、不要な個人情報は送信しないでください。
- **最小のモードから始める:** 調査はPlan、通常作業はAskを選び、必要な場合だけ権限を広げます。
- **信頼できるプロジェクトだけを開く:** PlanはPiの編集やコマンドを止める操作モードですが、
  信頼済みプロジェクトに含まれるPi拡張コードを隔離するサンドボックスではありません。入手元と
  内容を確認できないプロジェクトでは、VS CodeのWorkspace Trustを有効にしないでください。
- **実行内容を読む:** Askでは承認前に対象とコマンドを確認します。Auto Editでは通常のコマンドが
  自動実行され、削除や既知の高リスク操作だけが確認対象です。スクリプトを介した影響は完全には
  判定できないため、依頼を送る前にPiへ任せる範囲を確認してください。
- **変更をレビューする:** Piの変更後は差分を確認し、テストしてからコミットします。

添付内容は送信時に拡張機能側で再確認されます。既定の上限は、1ファイル512 KiB、
1フォルダー200ファイル、1回の依頼で合計2 MiBです。上限はVS Code設定の
`Pi Agent: Context` で変更でき、合計は最大8 MiBです。最終的な依頼文が安全なサイズに
収まらない場合は、一部の添付内容を省略し、そのことをPiへ伝えます。

## 困ったとき

| 状況 | 確認すること |
| --- | --- |
| チャットが見つからない | コマンドパレットで `Pi Agent: Open Chat` を実行します |
| モデルが表示されない | **Configure provider…** で正しいプロバイダーIDとAPIキーを再入力します |
| D&Dしても添付されない | チップがなければ添付ボタン、`@`検索、Explorerの右クリックを試します |
| 編集やコマンドを実行できない | フォルダーのWorkspace Trustと、Plan以外の操作モードを確認します |
| Workspace Trustを付与してもモードを変更できない | 通常は自動でwindowを再読み込みします。警告が出た場合はコマンドパレットの **Developer: Reload Window** を実行します |
| モデルやモードを変更できない | 応答の完了を待つか、**Stop** で停止してから変更します |
| costがUnavailableになる | モデルカタログに価格情報がない場合は正常です。サブスクリプションでも推定値は表示され得ます |

解決しない場合は、VS Codeの **Output（出力）** パネルで **Pi Agent** を選び、エラーを確認して
[GitHub Issues](https://github.com/karimatayuta/pi-vscode/issues)へ報告してください。APIキーや
プロジェクトの機密情報は、ログやIssueへ貼り付けないでください。

## 対応環境

- Visual Studio Code 1.106以降
- このPC上のローカルフォルダー（`file://`ワークスペース）
- 利用するAIモデルに必要なプロバイダー認証とネットワーク接続

Remote-SSH、WSL、Dev Containers、GitHub Repositoriesなど、リモート／Virtual Workspaceには
対応していません。プレビュー版のため、重要なプロジェクトではバージョン管理とバックアップを
併用してください。

## コマンドパレット

| コマンド | 用途 |
| --- | --- |
| `Pi Agent: Open Chat` | 右側のチャットを開く |
| `Pi Agent: New Chat` | 独立した新しいチャットを作る |
| `Pi Agent: Show Chat History` | 開いているチャットと保存済み履歴を表示 |
| `Pi Agent: Add Context…` | ファイルまたはフォルダーを添付 |
| `Pi Agent: Add Current File to Context` | 現在のファイルを添付 |
| `Pi Agent: Add Current Selection to Context` | 選択中のコードを添付 |
| `Pi Agent: Configure Provider…` | プロバイダーのAPIキーを設定 |
| `Pi Agent: Stop` | 進行中の応答とツールを停止 |
| `Pi Agent: Open Settings` | Pi AgentのVS Code設定を開く |
| `Pi Agent: Reset Saved Permissions` | セッション中に保存した許可を取り消す |
